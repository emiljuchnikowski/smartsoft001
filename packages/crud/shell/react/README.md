# @smartsoft001/crud-shell-react

The React CRUD screens of the smartsoft001 framework: the list and item pages generated from a
configuration object and the model's metadata, the filters, and the CRUD service with its store and
facade, speaking the REST contract of
[`@smartsoft001/crud-shell-nestjs`](https://www.npmjs.com/package/@smartsoft001/crud-shell-nestjs).

```bash
npm install @smartsoft001/crud-shell-react @smartsoft001/react react
```

The full documentation is at https://framework.smartflow.biz.pl/docs/packages/crud-shell-react/.
